# How to Integrate a Zoom App with Next.js

This project hosts a codelab demonstrating how to add Chatbot and Team Chat features to a Next.js Task Manager application. It is part of a multi-step series on building a multi-feature Zoom application.

## Prerequisites
- Node.js (recent LTS)
- Git
- Zoom Developer account
- Supabase account
- Ngrok account

## Quick Start
1. Clone the sample app:
   ```bash
   git clone https://github.com/zoom/task-manager-sample.git
   cd task-manager-sample
   git checkout step-1-zoom-install
   ```
2. Install dependencies and start the dev server:
   ```bash
   npm install
   npm run dev
   ```
3. Follow `index.html` to integrate Zoom Chatbot and Team Chat capabilities.
